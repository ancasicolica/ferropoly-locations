# Ferropoly Locations

Tool um die Datenbank des Ferropolys à jour zu halten. Mehr Info unter www.ferropoly.ch

## Source Dateien

### SBB Dienstellen DiDok

  * https://data.sbb.ch/explore/dataset/dienststellen-gemass-opentransportdataswiss/information/
  * dann "Exporte"
  * Flache Dateiformate, CSV vollständiger Datensatz

  In diesen Verzeichnis speichern als "didok.csv"

### Location DB

  * Als Admin im Editor herunterladen

  In diesem Verzeichnis speichern mit dem geladenen Namen (z.B. locationDb-261107-094825.json), es wird die neuste Datei verwendet
